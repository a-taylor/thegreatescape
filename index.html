The Great Escape

A browser recreation of the 1986 ZX Spectrum game, derived only from David Thomas's SkoolKit disassembly. Press 1–4 to choose an input device and 0 to start; the keyboard then asks you to define five keys.

O P Q A walk — left, right, up, down. Those are only the defaults this harness assumes: the shipped keydefs ($F06B) are all zero, and choose_keys is the only thing that ever fills them in, so skipping the menu means inventing a set. The four screen directions map onto the four world diagonals, so pressing a direction you are not already facing turns the hero rather than moving him — exactly as the animindices table dictates. Walk into a door to change room.

Space is fire, and fire plus a direction is an item command, exactly as process_player_input_fire ($7AC9) reads it: Space+Q picks up, Space+A drops, Space+O uses the first held item and Space+P the second. Fire on its own, and fire with two directions at once, do nothing at all — the routine tests only those four values. A fire command never moves the hero. All five are player-defined via choose_keys ($F350); load the page without ?debug=1 to define them yourself.

Pick-up radius is 1 outdoors and 6 indoors, and find_nearby_item returns the first item by index, not the nearest — so in a pile you get the lowest-numbered one. Each item scores 5 the first time it is picked up and never again.

P pauses and . advances a single tick while paused — debug scaffolding for catching a rendering fault mid-motion, not part of the original game. The status line records the paused state so a screenshot carries it.
