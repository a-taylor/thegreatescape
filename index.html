The Great Escape — walkable hero

256×192 Spectrum display: a 1-bit pixel buffer plus a 32×24 attribute grid. The 192×128 game window is blitted from a 24×17 tile buffer through the 128 row pointers of game_window_start_addresses.

←→↑↓ walk. The four screen directions map onto the four world diagonals, so pressing a direction you are not already facing turns the hero rather than moving him — exactly as the animindices table dictates. Walk into a door to change room.
